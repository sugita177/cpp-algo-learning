# 1.2 整数型とオーバーフロー対策

## 1. 整数型の境界値と相場観

競技プログラミングにおいて、型選択ミスによるオーバーフローは最も頻出する WA（誤答）の原因となる。

| 型 | ビット幅 | 最大値（概算） | 正確な値 |
| :--- | :---: | :---: | :---: |
| **`int`** | 32bit | $\approx 2 \times 10^9$ | $2^{31}-1 = 2,147,483,647$ |
| **`long long`** (`ll`) | 64bit | $\approx 9 \times 10^{18}$ | $2^{63}-1 = 9,223,372,036,854,775,807$ |

### 即座に `long long` を選ぶべき典型パターン
1. **総和・累積和**:
   - $N = 2 \times 10^5$, 各要素 $A_i = 10^9$ のとき、合計値は $\sum A_i \le 2 \times 10^{14}$ に達する。$2 \times 10^9$ を超えるため必須。
2. **積・幾何計算**:
   - 座標や辺長が $10^5$ を超える値同士の乗算（$10^5 \times 10^5 = 10^{10}$）で即座に `int` を突破する。
3. **等差数列の和**:
   - $\frac{N(N+1)}{2}$ は $N = 10^9$ のとき約 $5 \times 10^{17}$ に達する。

### 配列の添字に `long long` は必要か？
- **原則不要（`int` で十分）**。
- 競プロのメモリ制限（通常 1024MB）では、配列サイズはせいぜい $N \le 10^7$ 程度しかメモリ上に確保できない（`int` で $2 \times 10^9$ 個確保すると約 8GB で MLE）。
- したがって、配列のインデックスやループ変数 `i` は `int` で安全に扱える。

## 2. 遭遇しやすいオーバーフローの罠

### ① ビットシフトの未定義動作
```cpp
// NG例（未定義動作）
long long x = 1 << 40;
```
- リテラル `1` は 32bit `int`。
- C++ の仕様上、**型のビット幅（32bit）以上のシフト演算は未定義動作 (Undefined Behavior)** となる。
- **対策**: `1LL << 40` とし、64bit 整数リテラルとしてシフトさせる。

### ② 乗算途中のオーバーフロー（評価タイミングの罠）
```cpp
// NG例
int a = 1'000'000;
int b = 1'000'000;
long long c = a * b; // a * b の瞬間に 32bit オーバーフローしてゴミ値になる
```
- 代入先が `long long` であっても、右辺の式 `a * b` は「`int` 同士の乗算」としてまず 32bit の世界で計算される。
- **対策**:
  - `1LL * a * b` または `static_cast<ll>(a) * b` で 64bit に型昇格させる。
  - **推奨**: そもそも $10^9$ クラスになり得る変数は入力時点で `ll a, b;` と宣言しておく。

### ③ 括弧内の先行オーバーフロー
```cpp
// 注意が必要な例
int N = 2'000'000'000;
ll sum = 1LL * N * (N + 1) / 2; // (N + 1) で 32bit int を突破する恐れ
```
- `1LL * N` は 64bit だが、`(N + 1)` の計算自体は括弧内で `int` 同士として先に評価される。
- これを防ぐためにも、巨大な数は宣言時から `ll N;` としておくのが最も安全。

## 3. 実践コード

```cpp
#include <iostream>

using namespace std;
using ll = long long;

int main() {
  cin.tie(nullptr);
  ios::sync_with_stdio(false);

  int N;
  cin >> N; // 10^9
  int k;
  cin >> k; // 40
  int A;
  cin >> A; // 10^9
  int B;
  cin >> B; // 10^9

  ll sum = 1LL * N * (N + 1) / 2;
  cout << sum << "\n";
  ll power_two = 1LL << k;
  cout << power_two << "\n";
  ll large_val = 1LL * A * B;
  cout << large_val << "\n";

  return 0;
}
```
