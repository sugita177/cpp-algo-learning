# 1.5 参照渡し・コピーコスト・符号なし型の罠

## 1. 関数の引数とコピーコスト

競技プログラミングにおいて、関数引数の渡し方を誤ると、アルゴリズムが正しくても **「隠れ $O(N)$ コピー」** により致命的な TLE を引き起こす。

| 渡し方 | 構文例 | 内部動作 | 呼び出しコスト | 用途 |
| :--- | :--- | :--- | :---: | :--- |
| **値渡し** | `void f(vector<ll> v)` | 実体をまるごとヒープ再確保してディープコピー | **$O(N)$** | 関数内で独立して変更したい場合（競プロでは稀） |
| **参照渡し** | `void f(vector<ll>& v)` | 実体へのエイリアス（ポインタ）を渡す | **$O(1)$** | **元の配列の中身を直接書き換えたい場合** |
| **const 参照渡し** | `void f(const vector<ll>& v)` | 読み取り専用ポインタを渡す | **$O(1)$** | **中身を変更せず参照・検索・集計する場合の鉄則** |

### ⚠️ コピーコスト TLE の計算例
要素数 $N = 2 \times 10^5$ の配列に対し、クエリ等で関数を $Q = 2 \times 10^5$ 回呼ぶ場合：
- **値渡し**: $O(Q \times N) = 4 \times 10^{10}$ 回のメモリアクセス $\to$ **確実に TLE（数十秒以上）**
- **const 参照渡し**: 呼び出しコストは $O(1)$ $\to$ **一瞬（0.01 秒未満）**

## 2. `size()` の符号なしアンダーフロートラップ

`v.size()` や `s.length()` の戻り値の型は、**符号なし整数（`size_t` / `unsigned long long`）** である。

```cpp
vector<int> v; // 空の配列 (v.size() == 0)

// 💣 危険なコード
for (int i = 0; i < v.size() - 1; ++i) {
    cout << v[i] << " " << v[i + 1] << "\n";
}
```

### なぜ無限ループ / 配列外参照（RE）になるのか？
- 符号なしの世界には負の数が存在しないため、`0 - 1` を計算した瞬間に **ラップアラウンド（アンダーフロー）** が発生する。
- 64bit 環境では、$0 - 1$ の結果は **$2^{64} - 1 = 18,446,744,073,709,551,615$（約 $1.84 \times 10^{19}$）** という超巨大な正の数に化ける。
- ループ条件が `i < 18446744073709551615` と判定され、空の配列に対して `v[0], v[1], ...` とアクセスを試みて **即座に Segmentation Fault（RE）** となる。

## 3. アンダーフローを防ぐ 3 つの実戦イディオム

### ① C++20 `std::ssize(v)` を使う（モダンな推奨手法）
`std::ssize(v)` は符号付き整数（`ptrdiff_t`）を返すため、`0 - 1` は正しく `-1` になる。
```cpp
for (int i = 0; i < ssize(v) - 1; ++i)
```

### ② 引き算を「足し算」に変える（鉄板の競プロイディオム）
両辺に 1 を足して不等式を移項する。引き算がそもそも発生しないため、型を問わず安全。
```cpp
for (int i = 0; i + 1 < v.size(); ++i)
```

### ③ ガード節（早期リターン）
関数の先頭で要素数をチェックして弾く。
```cpp
if (v.size() <= 1) return;
```

## 4. 範囲 for 文の使い分け

| 構文 | 動作 | 適した場面 |
| :--- | :--- | :--- |
| `for (const auto& x : v)` | コピーなし・読み取り専用 | 各要素の表示・集計・判定 |
| `for (auto& x : v)` | コピーなし・書き換え可能 | **各要素のインプレース書き換え** |
| `for (auto x : v)` | 値コピー | `int` や `char` など軽量な基本型で書き換えても良い場合 |

## 5. 実践コード

```cpp
/**
 * Phase 1.5: 参照渡し・コピーコスト・符号なし型の罠
 */

#include <iostream>
#include <vector>

using namespace std;
using ll = long long;

// 1. 参照渡しによるインプレース更新 (コピーコスト O(1))
void modify_elements(vector<ll> &v) {
  for (auto &x : v) {
    if (x % 2 == 0) {
      x /= 2;
    } else {
      x *= 3;
    }
  }
}

// 2. const 参照渡しによる読み取り (ssize によるアンダーフロー防止)
void print_adjacent_diffs(const vector<ll> &v) {
  for (int i = 0; i < ssize(v) - 1; i++) {
    cout << abs(v[i + 1] - v[i]) << '\n';
  }
}

int main() {
  cin.tie(nullptr);
  ios::sync_with_stdio(false);

  int N;
  cin >> N;
  vector<ll> a(N);
  for (int i = 0; i < N; i++) {
    cin >> a[i];
  }
  modify_elements(a);
  print_adjacent_diffs(a);

  return 0;
}
```
