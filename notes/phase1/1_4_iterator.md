# 1.4 イテレータの仕組みと区間概念

## 1. 半開区間 `[begin, end)` の設計思想

C++ の標準ライブラリ（STL）は、閉区間 `[first, last]` ではなく、末尾要素の「1つ後ろの架空の場所」を指す **半開区間 `[begin, end)`** を採用している。

### なぜ半開区間なのか？
1. **要素数の計算が引き算だけで完結する**:
   - `end - begin` で正確な要素数（サイズ）が求まる（閉区間のように `+ 1` が不要）。
2. **「空（要素数 0）」を自然に表現できる**:
   - 閉区間 $[a, b]$ で要素数 0 を表すには $b = a - 1$ となり負数や不正ポインタが必要になるが、半開区間なら **`begin == end`** とするだけで自然に表現できる。
3. **区間の分割・結合で境界が被らない**:
   - 区間 $[0, N)$ を半分に割る際、$[0, M)$ と $[M, N)$ のように境界値 $M$ が重複せず綺麗に接続できる。
4. **ループの終了判定が単純**:
   - `it != end` で自然に判定可能。

## 2. ランダムアクセスイテレータ vs 双方向イテレータ

コンテナの内部メモリ構造によって、イテレータの移動能力と計算量が根本的に異なる。

| イテレータ種別 | 主なコンテナ | 内部構造 | `it + k` (直接加算) | 計算量 |
| :--- | :--- | :--- | :---: | :---: |
| **ランダムアクセス** | `vector`, `deque`, 配列 | **連続メモリ**（一直線） | **可能** | **$O(1)$** |
| **双方向** | `set`, `map`, `list` | **木構造 / ノード連結** | **不可（コンパイルエラー）** | **$O(k)$** |

### メモリ構造の違い
- **`vector`**: 要素がメモリ上に隙間なく並んでいるため、アドレス計算 `base + k * sizeof(T)` の掛け算 1 発で一瞬に $k$ 個先へジャンプできる。
- **`set`（赤黒木）**: メモリ上のあちこちに散らばるノードがポインタ（親子関係）で結ばれているため、1 歩ずつポインタを辿る（トラバースする）必要がある。
  - 移動関数: `std::advance(it, k)` または `std::next(it, k)`
  - 計算量: $k$ ステップ辿るため **$O(k)$**

## 3. イテレータの距離とインデックス取得

```cpp
int idx = it - vec.begin(); // または std::distance(vec.begin(), it);
```

- **`vector`**: ポインタ同士の引き算なので **$O(1)$**。
- **`set`**: `begin()` から `it` まで 1 つずつ `++` して数えるため **$O(k)$（最悪 $O(N)$）**。
  - ⚠️ **落とし穴**: `set` の中で「今何番目の要素か？」を何度も求めると即座に TLE となる。

## 4. `lower_bound` の仕様と境界値ガード

### 仕様
- **前提**: 対象コンテナが **昇順にソート済み** であること。
- **戻り値**: 指定した値 $X$ **以上（$\ge X$）** である最初の要素を指すイテレータ。
- **未発見時**: すべての要素が $X$ より小さい場合、末尾の **`end()`** を返す。

### ⚠️ 超重要: `set` における呼び出し方の罠
- `vector`: `std::lower_bound(vec.begin(), vec.end(), X)` $\to$ **$O(\log N)$（二分探索）**
- `set`: 汎用関数 `std::lower_bound(st.begin(), ...)` は **$O(N)$ で TLE**！
  - **必ずメンバ関数 `st.lower_bound(X)` を使用する**（木を根から辿って **$O(\log N)$**）。

### 終端・先頭のデリファレンス未定義動作ガード
- `it == end()` のときに `*it` を参照（デリファレンス）すると、**配列外参照（未定義動作 / RE）** となる。
- `it == begin()` のときに `std::prev(it)` や `--it` を呼ぶと、**範囲外アクセスの未定義動作** となる。
- 必ず条件分岐でガードすること。

## 5. 実践コード

```cpp
/**
 * Phase 1.4: イテレータの仕組みと区間概念
 * 
 * 【問題】
 * ソート済み配列 A (要素数 N) と Q 個のクエリ X が与えられる。
 * 各クエリに対し、lower_bound を用いて X 以上の最初の要素を指すイテレータ it を取得し、以下を出力する:
 * 1. 要素の 0-indexed インデックス (存在しない場合は -1)
 * 2. 要素の値 (存在しない場合は -1)
 * 3. 1つ前の要素の値 (it が先頭の場合または存在しない場合は -1)
 */

#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

int main() {
  cin.tie(nullptr);
  ios::sync_with_stdio(false);

  int N, Q;
  cin >> N >> Q;
  vector<int> A(N);
  for (int i = 0; i < N; i++) {
    cin >> A[i];
  }
  for (int i = 0; i < Q; i++) {
    int X;
    cin >> X;
    auto it = lower_bound(A.begin(), A.end(), X);
    if (it == A.end()) {
      cout << -1 << " " << -1 << " " << -1 << '\n';
    } else {
      int idx = it - A.begin();
      int val = *it;
      int prev = (idx > 0) ? A[idx - 1] : -1;
      cout << idx << " " << val << " " << prev << '\n';
    }
  }

  return 0;
}
```
