# 3.1 累積和・2次元累積和

## 1. 1次元累積和と「1-indexed 設計」の真価

配列 $A$ の区間和を毎回計算すると $O(N)$ かかるが、事前に累積和配列を作っておけば **$O(1)$** で計算できる。

### なぜ 1-indexed（サイズ $N+1$）にするのか？
- **$S[k]$ の定義**: **「元の配列の先頭から $k$ 個分の総和」**（$S[0] = 0$ は「0 個分の和」）。
- **半開区間 $[L, R)$（0-indexed）の和**:
  - 先頭から $R$ 個分の和（$S[R]$）から、先頭から $L$ 個分の和（$S[L]$）を引くだけ。
  - 計算式: **`S[R] - S[L]`**

> 💡 **最大のメリット: 添字 `-1`（配列外参照 RE）の完全消滅**
> - 先頭を含む区間 $[0, R)$ を求めたいとき、式にそのまま代入すると `S[R] - S[0] = S[R] - 0 = S[R]` となる。
> - 0-indexed 設計だと $S[R-1] - S[L-1]$ となり、$L=0$ のときに $S[-1]$ になるため `if (L == 0)` の分岐が必要だったが、**1-indexed 設計なら分岐が一切不要** になる。

## 2. 2次元累積和と包除原理

サイズ $H \times W$ のグリッドにおいて、任意の長方形領域の総和を **事前計算 $O(HW)$、クエリ $O(1)$** で求めるアルゴリズム。
サイズ $(H+1) \times (W+1)$ の配列 $S$ を用意する（0 行目・0 列目はすべて 0 の「外枠」ガード）。

```text
       0        c1-1        c2
   0   +----------+----------+
       |          |          |
  r1-1 +----------+----------+
       |          | ★求めたい|
   r2  +----------+----------+
```

### ① 構築式（事前計算: $O(HW)$）
マス $(i, j)$ までの累積和 $S[i][j]$ は、上の長方形と左の長方形を足し、重複した左上を引き、今のマスを足す（包除原理）。
$$S[i][j] = S[i-1][j] + S[i][j-1] - S[i-1][j-1] + A[i-1][j-1]$$

### ② クエリ式（領域和の取得: $O(1)$）
1-indexed の閉区間 $[r_1, r_2] \times [c_1, c_2]$ の総和は：
$$\text{Ans} = S[r_2][c_2] - S[r_1 - 1][c_2] - S[r_2][c_1 - 1] + S[r_1 - 1][c_1 - 1]$$

> 💡 **境界値ガードの威力**:
> もし $r_1 = 1, c_1 = 1$（左上端を含む領域）が指定されても、$r_1 - 1 = 0, c_1 - 1 = 0$ となり、安全に 0 番地（値は 0）を参照するため、**端っこの場合分けコードが一切不要** になる。

## 3. 実践コード

```cpp
/**
 * Phase 3.1: 累積和・2次元累積和
 */

#include <iostream>
#include <vector>

using namespace std;
using ll = long long;

int main() {
  cin.tie(nullptr);
  ios::sync_with_stdio(false);

  int H, W, Q;
  cin >> H >> W >> Q;

  vector<vector<ll>> A(H, vector<ll>(W));
  for (int i = 0; i < H; ++i) {
    for (int j = 0; j < W; ++j) {
      cin >> A[i][j];
    }
  }

  // 1. (H+1) x (W+1) の 1-indexed 累積和配列を構築
  vector<vector<ll>> S(H + 1, vector<ll>(W + 1, 0));
  for (int i = 1; i <= H; ++i) {
    for (int j = 1; j <= W; ++j) {
      S[i][j] = S[i - 1][j] + S[i][j - 1] - S[i - 1][j - 1] + A[i - 1][j - 1];
    }
  }

  // 2. 各クエリを O(1) で処理
  for (int i = 0; i < Q; ++i) {
    int r1, c1, r2, c2;
    cin >> r1 >> c1 >> r2 >> c2;
    ll ans = S[r2][c2] - S[r1 - 1][c2] - S[r2][c1 - 1] + S[r1 - 1][c1 - 1];
    cout << ans << '\n';
  }

  return 0;
}
```
