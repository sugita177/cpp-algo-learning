# 3.5 動的計画法 (DP基礎: 0-1 ナップサック・1次元化・解の復元)

## 1. 0-1 ナップサック問題の基本設計

### 状態定義
- `dp[i][w]` : 最初の $i$ 個の品物の中から、重さの合計が $w$ 以下となるように選んだときの「価値の最大値」

### 状態遷移（漸化式）
品物 $i$（0-indexed で $i-1$ 番目）について：
- **選ばない場合**: 直前 $i-1$ までの最適解をそのまま引き継ぐ
  $$dp[i][w] = dp[i-1][w]$$
- **選ぶ場合** ($w \ge w_i$): 品物 $i$ の重さ分を空けた状態の最適解に価値 $v_i$ を加算する
  $$dp[i][w] = dp[i-1][w - w_i] + v_i$$

両者のうち大きい方を採用する：
$$dp[i][w] = \max(dp[i-1][w], \; dp[i-1][w - w_i] + v_i)$$

### 計算量
- **時間計算量**: $O(N \times W)$
- **空間計算量**: $O(N \times W)$（2次元テーブルの場合）

---

## 2. 空間計算量の最適化（1次元配列化）とループの向き

### なぜ 1 次元配列に圧縮できるのか？
`dp[i][w]` を計算する際、参照しているのは **直前の行 `dp[i-1][*]` のみ** であり、2行以上前のデータは不要です。  
したがって、配列を `vector<ll> dp(W + 1, 0);` の 1 本にまとめることができます。

### ⚠️ ループの向きの罠（降順 vs 昇順）

| ループ方向 | 遷移時に参照される値 | アルゴリズムの意味 |
| :--- | :--- | :--- |
| **降順 ($w = W \to w_i$)** | **未更新（直前の行 $i-1$）の値** | **0-1 ナップサック（各品物 高々1個）** |
| **昇順 ($w = w_i \to W$)** | **既に今回のループで更新された値** | **完全ナップサック（各品物 無制限に使用可）** |

```cpp
// ⭕️ 0-1 ナップサック: 降順に回す
for (int i = 0; i < N; ++i) {
    for (int j = W; j >= w[i]; --j) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}

// 💡 個数無制限ナップサック: 昇順に回す
for (int i = 0; i < N; ++i) {
    for (int j = w[i]; j <= W; ++j) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

## 3. 初期化のルール（「以下」 vs 「ちょうど」）

| 条件 | 初期化 | 理由 |
| :--- | :--- | :--- |
| **重さ $W$ 以下** の最大値 | `dp` 全体を `0` | 何も入れなければ重さ 0・価値 0。容量が余っても良いため。 |
| **重さ ちょうど $W$** の最大値 | `dp[0] = 0`<br>それ以外 `-INF` | 作れない重さから遷移した不正解を混入させないため。<br>`dp[j - w[i]] == -INF` の場合は遷移をスキップする。 |
| **部分和問題** (達成可能性) | `dp[0] = true`<br>それ以外 `false` | 真偽値 DP。`dp[j] \|= dp[j - a[i]]` で遷移。 |

---

## 4. DP の解の復元（最適解の経路特定）

「最大価値」だけでなく、**「最適解を達成するために選んだ品物の組み合わせ」** を特定したい場合、1次元化すると履歴が失われるため **2次元テーブル `dp[i][w]`** を保持して逆算（バックトラッキング）します。

```cpp
// 2次元 DP テーブルの構築
vector<vector<ll>> dp(N + 1, vector<ll>(W + 1, 0));
for (int i = 0; i < N; ++i) {
    for (int j = 0; j <= W; ++j) {
        // 選ばない場合
        dp[i + 1][j] = dp[i][j];
        // 選ぶ場合
        if (j >= w[i]) {
            dp[i + 1][j] = max(dp[i + 1][j], dp[i][j - w[i]] + v[i]);
        }
    }
}

// 解の復元: (N, W) から過去へ遡る
int cur_w = W;
vector<int> chosen_indices;

for (int i = N; i >= 1; --i) {
    // 直前の行と値が同じなら、品物 i-1 は「選んでいない」
    if (dp[i][cur_w] == dp[i - 1][cur_w]) {
        continue;
    } else {
        // 直前の行と値が異なるなら、品物 i-1 を「選んだ」
        chosen_indices.push_back(i - 1);
        cur_w -= w[i - 1]; // 使った重さを差し引く
    }
}

// 0 からの昇順に並び替え
reverse(chosen_indices.begin(), chosen_indices.end());
```
