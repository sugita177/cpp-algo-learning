# 3.3 いもす法 (imos法)

## 1. いもす法とは？（区間加算の計算量革命）

「区間 $[L, R)$ に値 $V$ を加算する」というクエリが大量（$Q$ 回）に発生する問題において、愚直に毎回ループを回すと $O(Q \times T)$（例: $10^5 \times 10^5 = 10^{10}$ 回）かかり、確実に TLE する。

いもす法は、**「両端だけに加減算のマークを打っておき（$O(1)$）、全クエリ終了後に 1 回だけ累積和を取る（$O(T)$）」** というアプローチにより、全体計算量を **$O(Q + T)$** に劇的に削減するアルゴリズム。

---

## 2. 1次元いもす法の仕組み

半開区間 $[L, R)$（$L \le t < R$）に値 $V$ を一括加算する場合：

```text
タイムライン:    ...  L          R  ...
マーク      :       +V         -V
事後累積和  :    0000 V V V V V 0000
```

1. **始点 $L$**: `D[L] += V;`（ここから効果が始まる）
2. **終点 $R$**: `D[R] -= V;`（半開区間なので $R$ は効果が切れる最初の地点）
3. **復元（累積和）**:
   ```cpp
   for (int t = 1; t < T_MAX; ++t) {
       D[t] += D[t - 1];
   }
   ```

---

## 3. 2次元いもす法（長方形領域の加算）

長方形領域 $[r_1, r_2) \times [c_1, c_2)$ に一括 $+V$ する場合、四隅にマークを打つ。

```text
       c1         c2
  r1   +V        -V
  r2   -V        +V
```

1. **四隅マーキング**:
   - `D[r1][c1] += V;`
   - `D[r1][c2] -= V;`
   - `D[r2][c1] -= V;`
   - `D[r2][c2] += V;`
2. **復元（2段階累積和）**:
   - まず **横方向** に 1 次元累積和を取る。
   - 次に **縦方向** に 1 次元累積和を取る。
   - たったこれだけで全マスの一括加算が完了する。

---

## 4. ⚠️ 遭遇した落とし穴とデバッグの学び

### ① 「人数 $N$」と「時刻 $T$」の配列サイズ混同（ASan 検知！）
- `vector<int> x(N);` と宣言してしまうと、人数 $N=4$ なのに時刻 $S=1, T=8$ にアクセスして **Heap Buffer Overflow（配列外参照 RE）** が発生する。
- **対策**: いもす法の配列サイズは、人数ではなく **「時刻の最大値 $T_{\max} + 5$」** を確保する。
```cpp
constexpr int T_MAX = 200000 + 5;
vector<int> x(T_MAX, 0);
```

### ② `constexpr` の利点
- `constexpr int T_MAX = 200005;` と書くことで、コンパイル時に値が完全に確定し、実行時オーバーヘッドがゼロになる。

### ③ 最大値探索の境界値（時刻 0）
- 累積和の更新ループは `i = 1` から回すが、**最大人数を探すループは必ず `i = 0` から回す**。
- 時刻 0 から最大人数になるケース（入力例 2）での見落としを防ぐ。

---

## 5. 実践コード

```cpp
/**
 * Phase 3.3: いもす法 (imos法)
 */

#include <iostream>
#include <vector>

using namespace std;

int main() {
  cin.tie(nullptr);
  ios::sync_with_stdio(false);

  int N;
  cin >> N;

  vector<int> S(N), T(N);
  for (int i = 0; i < N; ++i) {
    cin >> S[i] >> T[i];
  }

  // 1. 時刻の最大サイズで確保
  constexpr int T_MAX = 200000 + 5;
  vector<int> x(T_MAX, 0);

  // 2. 始点と終点のマーキング (各 O(1))
  for (int i = 0; i < N; ++i) {
    x[S[i]]++;
    x[T[i]]--;
  }

  // 3. 累積和で各時刻の人数を復元 (O(T_MAX))
  for (int i = 1; i < T_MAX; ++i) {
    x[i] += x[i - 1];
  }

  // 4. 時刻 0 から最大人数と最初の時刻を探索
  int max_val = 0;
  int max_idx = 0;
  for (int i = 0; i < T_MAX; ++i) {
    if (max_val < x[i]) {
      max_val = x[i];
      max_idx = i;
    }
  }

  cout << max_val << '\n';
  cout << max_idx << '\n';

  return 0;
}
```
